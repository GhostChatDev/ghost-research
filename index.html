1. Run BitNet on your computer

Official server entry point is run_inference_server.py. It starts llama-server on 127.0.0.1:8080 [9].

git clone --recursive https://github.com/microsoft/BitNet.git
cd BitNet
pip install -r requirements.txt
huggingface-cli download microsoft/BitNet-b1.58-2B-4T-gguf --local-dir models/BitNet-b1.58-2B-4T
python setup_env.py -md models/BitNet-b1.58-2B-4T -q i2_s
python run_inference_server.py -m models/BitNet-b1.58-2B-4T/ggml-model-i2_s.gguf --host 127.0.0.1 --port 8080

Use the GGUF file setup_env.py actually writes if the name differs. The README’s model card is microsoft/BitNet-b1.58-2B-4T [9].

2. Point Ghost Chat at it

Settings → Your providers. Ghost Chat charges nothing for your own provider [2]. A key in the page is only sent to the URL you type, as a Bearer token, and is not saved.

What the post actually says

        
On 21 Nov 2026, @simplifyinAI posted that Microsoft released bitnet.cpp, that it can run 100B-parameter 1-bit models on a CPU, with up to 6.17× faster inference and up to 82.2% lower energy use, and that it is open source [1]. Those figures match Microsoft’s own README, not just the post [9].

        
What is true

        
    
          
  • bitnet.cpp is Microsoft’s official inference stack for 1.58-bit (ternary) models, MIT licensed, on CPU and GPU [9].
    • 
          
  • On x86, Microsoft reports 2.37× to 6.17× speedups and 71.9% to 82.2% less energy versus full precision. On ARM, 1.37× to 5.07× and 55.4% to 70.0% less energy [9][39].
    • 
          
  • A 100B BitNet b1.58 model can run on one CPU at about human reading speed, 5–7 tokens per second. That result is from research model shapes, not a released 100B chat model you can download today [9][39].
    • 
          
  • The model you can actually download and chat with is BitNet b1.58 2B4T: 2.4B parameters, 4 trillion training tokens [9][16].
    • 
          
  • The server script starts llama-server, which speaks the OpenAI-style /v1 API [32][41]. That is the same shape Ghost Chat already accepts under Your providers [2].
    • 
        

        
What not to believe

        
    
          
  • “100B on your CPU” does not mean a 100B model as smart as a frontier chat model. The public chat model is 2.4B [16]. A reply on the post called 1-bit quality a degradation; Microsoft’s claim is competitive with full-precision models of similar size, not with Claude or GPT-class models [1][19].
    • 
          
  • Speed and energy numbers are versus llama.cpp fp16 on specific CPUs (Apple M2 Ultra, Intel i7-13700H), not versus a data-center GPU API [39].
    • 
          
  • This app cannot install BitNet inside Ghost Chat. Ghost Chat would need a product change to offer “run on my computer” as a button. Today the path is Your providers [2].
    • 
        

        
How this improves Ghost Chat

        
    
          
  • Free Magic Assistant messages are capped at 25 a day, with no tools [2]. Local BitNet can take the boring overflow: rewrites and summaries, without touching the balance.
    • 
          
  • Own-provider calls are not charged by Ghost Chat [2]. A local server is the extreme case of that: you pay electricity, not tokens.
    • 
          
  • Private notes can stay on the machine. Cloud models still do research, code, finance, and media, which a 2.4B CPU model should not pretend to do.
