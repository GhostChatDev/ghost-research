What deserves a real experiment?

Mobile reachability first

A phone's localhost is the phone—not a laptop. Check the actual authenticated request path before offering any local alternative.

Guard the destination

Never switch silently from local-only to cloud. Confirm privacy, tool support, context and price before retrying.

Evidence before claims

BitNet benchmarks are upstream findings, not measured Ghost Chat savings. A real server response and failure test must come next.
